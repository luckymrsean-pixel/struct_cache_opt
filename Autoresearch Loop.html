1

Skill 本体

ideatePrompt:

Shell 命令。框架通过 heredoc 把 git log + TSV tail 送入 stdin； 命令把 unified diff 写到 stdout。可以接任何 LLM 工具。 

# A: Python 脚本调 Claude API（推荐）
ideatePrompt: |
  python3 /home/sean/skill/run.py

# B: GitHub Copilot CLI
ideatePrompt: |
  gh copilot suggest -t shell

# C: Claude CLI
ideatePrompt: |
  claude -p "Output only a unified diff. Context:"

Skill 脚本读 stdin（约 80 行 context），stdout 输出合法的 git diff 格式。 退出码非零或 stdout 为空 → 本轮记为 ideate-fail，continue。

2

Terminal 初始化

setupCmds:

SSH / PTY 建立后依次执行的命令列表。在循环开始前运行一次； 若 terminal-dead 重连，也会重新运行全部命令。 

setupCmds:
  # GitHub CLI 鉴权（令牌存在本地文件）
  - gh auth login --with-token < ~/.gh-token

  # Git 身份（CI 机器上通常未配置）
  - git config user.email bot@build-host.local
  - git config user.name  autoresearch-bot

  # 环境变量（ccache / conda / nvm 等）
  - export CCACHE_DIR=/home/sean/.ccache
  - source /opt/conda/etc/profile.d/conda.sh && conda activate perf

任意一条命令退出码非零会抛异常并终止启动。不需要初始化时留空列表 setupCmds: []。

3

编译 / 测试脚本

guardCmd:  verifyCmd:

guardCmd 先编译检查（失败则立即 revert，不跑 verify）。 verifyCmd 跑性能测试，stdout 末 token 必须是纯数字。 

# 编译检查（超时 20 min）
guardCmd: |
  autoninja -C out/Release angle_perftests 2>&1 | tee build.log

# 性能测试 — stdout 末 token 必须是数字
verifyCmd: |
  perf stat -e cpu-cycles ./out/Release/angle_perftests \
    --gtest_filter='*DrawQuad*' --iterations=100 2>&1 \
    | grep cpu-cycles | awk '{print $1}' | tr -d ','

verifyCmd stdout 示例：1234567890（末 token 即 metric）。 若输出 cycles elapsed: 1234567890 也可以 — 取末 token。

4

错误诊断

diagCmd:

guardCmd 或 verifyCmd 失败后自动运行。输出首行会追加到 TSV desc 字段， 便于 review 时快速定位原因。留空则跳过。 

# 从 build.log 提取前 5 条 error
diagCmd: |
  grep -E "error:" build.log | head -5

# 测试日志中的 FAILED 行
diagCmd: |
  cat test.log | grep FAILED | head -3

# 不需要诊断时留空
diagCmd: ""

diagCmd 的退出码被忽略。TSV desc 示例： build-fail | src/foo.cpp:42: error: use of undeclared…

5

性能比较

direction:  metricLabel:  metricUnit:

框架把每轮的 metric 与 best 比较，决定 keep / revert。 direction 决定比较方向。 

# 越小越好 (cpu-cycles / latency / memory)
direction:   lower
metricLabel: cpu-cycles
metricUnit:  cycles

# 越大越好 (throughput / FPS / score)
direction:   higher
metricLabel: frames-per-second
metricUnit:  fps
plateau — 连续无改善后停止
plateauPatience: 8
TSV 文件路径
tsvPath: results.tsv
总迭代轮数
iterations: 20
送入 Skill 的历史行数
memoryDepth: 20

TSV 每行记录：iter · status · metric · delta · exit · warns · desc · ts。 status 枚举：baseline / keep / discard / no-op / crash。
